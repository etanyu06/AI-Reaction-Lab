# AI Reaction Lab Secure Storage Design

AI Reaction Lab stores sensitive participant research media. Storage must be private by default, access must be short-lived and authorization-checked, and object paths must be scoped to workspace/project/test/session ownership.

Supported storage backends:

- Supabase Storage for MVP simplicity.
- Cloudflare R2 for larger-scale multipart uploads and lower egress cost.

The database remains the source of truth for ownership, status, retention, and deletion. Object storage holds files only.

## 1. Bucket Structure

### Supabase Storage

Use private buckets:

```txt
recordings-private
clips-private
thumbnails-private
exports-private
```

Recommended MVP simplification:

```txt
research-media-private
```

Use one private bucket if operational simplicity matters more than separate lifecycle policies. Use multiple buckets if retention, worker permissions, or storage classes need to differ.

### Cloudflare R2

Use private buckets:

```txt
ai-reaction-lab-media-prod
ai-reaction-lab-exports-prod
```

R2 should not expose public bucket URLs. All reads and writes go through presigned URLs generated by trusted server code.

## 2. Object Key Naming Convention

All media keys include:

- `workspace_id`
- `project_id`
- `test_id`
- `session_id`
- media category
- server-generated object ID

Canonical format:

```txt
workspaces/{workspaceId}/projects/{projectId}/tests/{testId}/sessions/{sessionId}/{category}/{objectId}.{ext}
```

Categories:

```txt
raw/screen
raw/camera
raw/microphone
raw/combined
chunks/combined
processed/combined
clips
thumbnails
transcripts
exports
```

Examples:

```txt
workspaces/ws_123/projects/prj_123/tests/tst_123/sessions/ses_123/raw/combined/rec_123.webm
workspaces/ws_123/projects/prj_123/tests/tst_123/sessions/ses_123/chunks/combined/rec_123/chunk-000001.webm
workspaces/ws_123/projects/prj_123/tests/tst_123/sessions/ses_123/clips/clip_123.webm
workspaces/ws_123/projects/prj_123/tests/tst_123/sessions/ses_123/thumbnails/thumb_123.jpg
workspaces/ws_123/projects/prj_123/tests/tst_123/sessions/ses_123/transcripts/transcript_123.json
```

Rules:

- Never accept object paths from the browser.
- Server generates object IDs and paths.
- Do not put participant names, emails, URL slugs, or readable research titles in object keys.
- Avoid permanent public URLs.
- Store object path in Postgres `recordings`, `clips`, or export metadata.

## 3. Upload URL Flow

Upload URLs are generated only by trusted server code after authorization and validation.

Participant recording upload:

1. Participant consents.
2. Server creates or validates session.
3. Client requests upload URL with token, session ID, media type, MIME type, size, duration, and idempotency key.
4. Server validates participant token belongs to session.
5. Server validates consent is accepted.
6. Server validates file type, expected max size, expected max duration, and workspace usage limits.
7. Server creates a `recordings` row with `status = 'pending'`.
8. Server generates object key.
9. Server returns short-lived signed upload URL.
10. Client uploads directly to storage.
11. Client calls complete upload endpoint.
12. Server verifies object exists and metadata matches.
13. Server updates `recordings.status = 'uploaded'`.

Signed upload URL expiry:

- Recording upload URL: 5 to 10 minutes.
- Chunk upload URL: 5 minutes.
- Thumbnail upload URL: 2 to 5 minutes.
- Export upload URL: internal only.

Researcher/worker upload:

- Generated clips, thumbnails, transcript artifacts, and exports should be uploaded by trusted workers using service credentials or short-lived presigned URLs generated internally.

## 4. Download URL Flow

Read URLs are generated only after role and ownership checks.

Flow:

1. Authenticated user requests media playback/download.
2. Server verifies workspace membership.
3. Server verifies role is allowed for the media type.
4. Server fetches media metadata from Postgres.
5. Server verifies media is not deleted and not expired.
6. Server creates short-lived signed read URL.
7. Server writes audit log for sensitive media access.
8. Client receives signed URL.

Signed read URL expiry:

- Video playback: 60 to 300 seconds.
- Thumbnail: 5 to 15 minutes.
- Export file: 60 seconds.
- Clip playback: 60 to 300 seconds.

Do not return:

- Permanent object URLs.
- Raw storage paths to unauthorized clients.
- Bucket names in public participant APIs.
- Signed URLs for deleted or expired media.

## 5. Access Control Rules

Database authorization is required before storage access.

Authenticated users:

- `owner`, `admin`, `researcher`: can read recording metadata and request signed playback URLs.
- `viewer`: can read reports and sessions, but should not receive raw recording URLs unless product policy explicitly allows it.
- `owner`, `admin`: can delete/anonymize participant media.

Participants:

- No full account required.
- Can upload only to their own token-created session after consent.
- Cannot list buckets.
- Cannot read recordings after upload.
- Cannot read transcripts, AI reports, clips, or other sessions.

Workers:

- Can read/write media required for processing.
- Should use service credentials in server-only environments.
- Must not expose service credentials to browser.

Storage policy guidance:

- Supabase Storage buckets remain private.
- Prefer server-generated signed URLs over broad storage RLS policies.
- If using Supabase Storage RLS, match object path prefixes against authorized database rows, but still keep signed URL generation server-side for media reads.
- R2 access keys must be server-only and scoped to the media bucket where possible.

## 6. File Validation Rules

Validate before generating upload URL and after upload completion.

### Allowed File Types

Recordings:

```ts
const recordingMimeTypes = [
  "video/webm",
  "audio/webm",
  "video/mp4",
  "audio/mp4",
] as const;
```

Thumbnails:

```ts
const thumbnailMimeTypes = [
  "image/jpeg",
  "image/png",
  "image/webp",
] as const;
```

Transcript artifacts:

```ts
const transcriptMimeTypes = [
  "application/json",
  "text/plain",
] as const;
```

Exports:

```ts
const exportMimeTypes = [
  "text/markdown",
  "application/json",
  "text/plain",
] as const;
```

### Size Limits

Suggested MVP limits:

```txt
combined recording: 2 GB max
single chunk: 100 MB max
camera-only recording: 1 GB max
audio-only recording: 250 MB max
thumbnail: 5 MB max
transcript artifact: 25 MB max
clip: 500 MB max
export: 25 MB max
```

Also enforce workspace storage:

```txt
current_storage_bytes + incoming_size_bytes <= max_storage_bytes_per_workspace
```

### Duration Limits

Use test/workspace duration limit:

```txt
duration_seconds <= min(test.max_duration_seconds, usage_limits.max_recording_duration_seconds)
```

For clips:

```txt
clip.end_ms > clip.start_ms
clip.end_ms <= recording.duration_seconds * 1000
clip duration <= 5 minutes for MVP
```

### Ownership Validation

Never trust client ownership fields.

Server derives:

- `workspace_id`
- `project_id`
- `test_id`
- `session_id`

from the session/test rows after authorization.

### Post-Upload Validation

After upload:

- Confirm object exists.
- Confirm object size matches expected value or is within accepted tolerance.
- Confirm content type if storage provider returns it.
- Optionally verify checksum.
- Optionally probe media duration server-side with a worker.
- Mark suspicious uploads as `failed` and do not process.

## 7. Deletion Lifecycle

Deletion should have a database phase and a storage phase.

Immediate user action:

1. Authorize deletion.
2. Mark related DB rows as `deleted_at = now()`.
3. Mark recording/clip status as `deleted`.
4. Enqueue object deletion job.
5. Write audit logs.
6. Hide media immediately from UI and signed URL APIs.

Background deletion:

1. Worker reads deleted media rows with storage paths.
2. Worker deletes objects from storage.
3. Worker records deletion result.
4. Worker retries transient failures.

Anonymization:

- Remove participant identifiers from `participants`.
- Clear optional participant email/name/external ref.
- Clear IP hashes if policy requires.
- Keep media only if researcher has lawful/research basis and retention policy allows.
- If participant requests media deletion, delete recordings, clips, transcript artifacts, and thumbnails tied to the participant sessions.

Never hard-delete audit logs as part of participant media deletion. Audit logs should avoid unnecessary participant identifiers.

## 8. Retention Policy

Retention is workspace-driven with optional test override.

Fields:

- `workspaces.retention_days`
- `workspaces.anonymize_participants_after_days`
- `tests.retention_days`
- `sessions.delete_after_at`
- `recordings.delete_after_at`
- `transcripts.delete_after_at`
- `ai_reports.delete_after_at`

On session completion:

```txt
effective_retention_days = test.retention_days ?? workspace.retention_days
delete_after_at = completed_at + effective_retention_days
```

Scheduled retention job:

1. Find recordings where `delete_after_at <= now()` and `deleted_at is null`.
2. Soft-delete DB rows.
3. Delete storage objects.
4. Optionally keep derived non-identifying report data if workspace policy allows.
5. Write audit log event.

Recommended MVP defaults:

```txt
workspace retention: 90 days
participant anonymization: optional, unset by default
signed read URL expiry: 1 to 5 minutes
signed upload URL expiry: 5 to 10 minutes
```

## 9. Audit Logging

Audit sensitive storage actions:

- Upload URL created.
- Upload completed.
- Recording viewed.
- Clip viewed.
- Export created.
- Recording deleted.
- Clip deleted.
- Participant media anonymized/deleted.
- Retention deletion job completed.
- Suspicious upload rejected.

Audit payload should include:

```ts
type StorageAuditMetadata = {
  workspaceId: string;
  projectId?: string;
  testId?: string;
  sessionId?: string;
  recordingId?: string;
  clipId?: string;
  bucket?: string;
  objectCategory?: string;
  sizeBytes?: number;
  mimeType?: string;
  reason?: string;
};
```

Do not put signed URLs, raw IP addresses, participant emails, or access keys in audit logs.

## 10. Example TypeScript Functions

### Shared Types And Validators

```ts
import { z } from "zod";

export const uuidSchema = z.string().uuid();

export const recordingTypeSchema = z.enum([
  "screen",
  "camera",
  "microphone",
  "combined",
]);

export const uploadRequestSchema = z.object({
  sessionId: uuidSchema,
  token: z.string().min(32).max(256),
  recordingType: recordingTypeSchema,
  mimeType: z.enum(["video/webm", "audio/webm", "video/mp4", "audio/mp4"]),
  sizeBytes: z.number().int().min(1).max(2_000_000_000),
  durationSeconds: z.number().int().min(1).max(1200),
  checksumSha256: z.string().regex(/^[a-f0-9]{64}$/).optional(),
  idempotencyKey: z.string().min(16).max(128),
});

export type StorageObjectKeyInput = {
  workspaceId: string;
  projectId: string;
  testId: string;
  sessionId: string;
  category: string;
  objectId: string;
  extension: string;
};

export function buildObjectKey(input: StorageObjectKeyInput) {
  return [
    `workspaces/${input.workspaceId}`,
    `projects/${input.projectId}`,
    `tests/${input.testId}`,
    `sessions/${input.sessionId}`,
    input.category,
    `${input.objectId}.${input.extension}`,
  ].join("/");
}

export function extensionForMimeType(mimeType: string) {
  switch (mimeType) {
    case "video/webm":
    case "audio/webm":
      return "webm";
    case "video/mp4":
    case "audio/mp4":
      return "mp4";
    case "image/jpeg":
      return "jpg";
    case "image/png":
      return "png";
    case "image/webp":
      return "webp";
    case "application/json":
      return "json";
    case "text/plain":
      return "txt";
    case "text/markdown":
      return "md";
    default:
      throw new Error("Unsupported MIME type");
  }
}
```

### Generate Supabase Upload URL

```ts
import { createClient } from "@supabase/supabase-js";
import { randomUUID } from "crypto";

const MEDIA_BUCKET = "research-media-private";

export async function generateSupabaseRecordingUploadUrl(input: unknown) {
  const parsed = uploadRequestSchema.parse(input);

  const session = await getSessionForParticipantToken({
    sessionId: parsed.sessionId,
    token: parsed.token,
  });

  if (!session) {
    throw new AppError("NOT_FOUND", "Session not found");
  }

  if (session.consent_status !== "accepted") {
    throw new AppError("FORBIDDEN", "Consent is required before upload");
  }

  await assertRecordingWithinLimits({
    workspaceId: session.workspace_id,
    testId: session.test_id,
    sizeBytes: parsed.sizeBytes,
    durationSeconds: parsed.durationSeconds,
  });

  const recordingId = randomUUID();
  const extension = extensionForMimeType(parsed.mimeType);
  const objectKey = buildObjectKey({
    workspaceId: session.workspace_id,
    projectId: session.project_id,
    testId: session.test_id,
    sessionId: session.id,
    category: `raw/${parsed.recordingType}`,
    objectId: recordingId,
    extension,
  });

  await insertRecordingRow({
    id: recordingId,
    workspaceId: session.workspace_id,
    testId: session.test_id,
    sessionId: session.id,
    type: parsed.recordingType,
    status: "pending",
    storageBucket: MEDIA_BUCKET,
    storagePath: objectKey,
    mimeType: parsed.mimeType,
    sizeBytes: parsed.sizeBytes,
    durationSeconds: parsed.durationSeconds,
    checksumSha256: parsed.checksumSha256,
  });

  const supabaseAdmin = createClient(
    process.env.NEXT_PUBLIC_SUPABASE_URL!,
    process.env.SUPABASE_SERVICE_ROLE_KEY!,
    { auth: { persistSession: false } },
  );

  const { data, error } = await supabaseAdmin.storage
    .from(MEDIA_BUCKET)
    .createSignedUploadUrl(objectKey);

  if (error || !data) {
    throw new AppError("UPLOAD_FAILED", "Could not create upload URL");
  }

  await writeAuditLog({
    workspaceId: session.workspace_id,
    action: "recording_upload_url_created",
    resourceType: "recording",
    resourceId: recordingId,
    sessionId: session.id,
    metadata: {
      objectCategory: `raw/${parsed.recordingType}`,
      sizeBytes: parsed.sizeBytes,
      mimeType: parsed.mimeType,
    },
  });

  return {
    recordingId,
    uploadUrl: data.signedUrl,
    uploadMethod: "PUT" as const,
    expiresInSeconds: 120,
  };
}
```

### Complete Upload

```ts
export async function completeRecordingUpload(input: {
  sessionId: string;
  token: string;
  recordingId: string;
  sizeBytes: number;
  checksumSha256?: string;
}) {
  const recording = await getRecordingForParticipantToken(input);

  if (!recording) {
    throw new AppError("NOT_FOUND", "Recording not found");
  }

  const storageObject = await headStorageObject({
    bucket: recording.storage_bucket,
    key: recording.storage_path,
  });

  if (!storageObject.exists) {
    throw new AppError("UPLOAD_FAILED", "Uploaded object was not found");
  }

  if (storageObject.sizeBytes !== input.sizeBytes) {
    throw new AppError("VALIDATION_ERROR", "Uploaded object size mismatch");
  }

  await updateRecordingStatus({
    recordingId: recording.id,
    status: "uploaded",
    uploadedAt: new Date().toISOString(),
  });

  await incrementWorkspaceStorageUsage({
    workspaceId: recording.workspace_id,
    sizeBytes: input.sizeBytes,
  });

  await writeAuditLog({
    workspaceId: recording.workspace_id,
    action: "recording_uploaded",
    resourceType: "recording",
    resourceId: recording.id,
    sessionId: recording.session_id,
    metadata: {
      sizeBytes: input.sizeBytes,
      mimeType: recording.mime_type,
    },
  });

  return {
    recordingId: recording.id,
    status: "uploaded" as const,
  };
}
```

### Generate Signed Read URL

```ts
export async function generateRecordingReadUrl(input: {
  userId: string;
  workspaceId: string;
  recordingId: string;
}) {
  await requireWorkspaceRole(input.workspaceId, [
    "owner",
    "admin",
    "researcher",
  ]);

  const recording = await getRecordingById(input.recordingId);

  if (!recording || recording.workspace_id !== input.workspaceId) {
    throw new AppError("NOT_FOUND", "Recording not found");
  }

  if (recording.deleted_at || recording.status === "deleted") {
    throw new AppError("NOT_FOUND", "Recording not found");
  }

  if (
    recording.delete_after_at &&
    new Date(recording.delete_after_at).getTime() <= Date.now()
  ) {
    throw new AppError("NOT_FOUND", "Recording not found");
  }

  const supabaseAdmin = createAdminSupabaseClient();
  const expiresInSeconds = 180;

  const { data, error } = await supabaseAdmin.storage
    .from(recording.storage_bucket)
    .createSignedUrl(recording.storage_path, expiresInSeconds);

  if (error || !data) {
    throw new AppError("INTERNAL_ERROR", "Could not create playback URL");
  }

  await writeAuditLog({
    workspaceId: recording.workspace_id,
    actorUserId: input.userId,
    action: "recording_viewed",
    resourceType: "recording",
    resourceId: recording.id,
    sessionId: recording.session_id,
    metadata: {
      expiresInSeconds,
      objectCategory: recording.type,
    },
  });

  return {
    recordingId: recording.id,
    readUrl: data.signedUrl,
    expiresAt: new Date(Date.now() + expiresInSeconds * 1000).toISOString(),
  };
}
```

### Generate R2 Signed PUT URL

```ts
import { S3Client, PutObjectCommand, GetObjectCommand } from "@aws-sdk/client-s3";
import { getSignedUrl } from "@aws-sdk/s3-request-presigner";

export const r2 = new S3Client({
  region: "auto",
  endpoint: process.env.R2_ENDPOINT!,
  credentials: {
    accessKeyId: process.env.R2_ACCESS_KEY_ID!,
    secretAccessKey: process.env.R2_SECRET_ACCESS_KEY!,
  },

export async function createR2SignedPutUrl(input: {
  bucket: string;
  key: string;
  contentType: string;
  sizeBytes: number;
}) {
  const command = new PutObjectCommand({
    Bucket: input.bucket,
    Key: input.key,
    ContentType: input.contentType,
    ContentLength: input.sizeBytes,
  });

  return getSignedUrl(r2, command, { expiresIn: 300 });
}

export async function createR2SignedReadUrl(input: {
  bucket: string;
  key: string;
}) {
  const command = new GetObjectCommand({
    Bucket: input.bucket,
    Key: input.key,
  });

  return getSignedUrl(r2, command, { expiresIn: 180 });
}
```

### Delete Participant Media

```ts
export async function deleteParticipantMedia(input: {
  workspaceId: string;
  participantId: string;
  actorUserId: string;
  reason: string;
}) {
  await requireWorkspaceRole(input.workspaceId, ["owner", "admin"]);

  const sessions = await getSessionsForParticipant({
    workspaceId: input.workspaceId,
    participantId: input.participantId,
  });

  for (const session of sessions) {
    const mediaObjects = await getMediaObjectsForSession(session.id);

    await softDeleteSessionMedia(session.id);

    for (const object of mediaObjects) {
      await enqueueStorageDeletion({
        bucket: object.storage_bucket,
        key: object.storage_path,
        resourceType: object.resource_type,
        resourceId: object.id,
      });
    }

    await writeAuditLog({
      workspaceId: input.workspaceId,
      actorUserId: input.actorUserId,
      action: "recording_deleted",
      resourceType: "session",
      resourceId: session.id,
      sessionId: session.id,
      participantId: input.participantId,
      metadata: {
        reason: input.reason,
        objectCount: mediaObjects.length,
      },
    });
  }

  await anonymizeParticipant(input.participantId);

  await writeAuditLog({
    workspaceId: input.workspaceId,
    actorUserId: input.actorUserId,
    action: "participant_anonymized",
    resourceType: "participant",
    resourceId: input.participantId,
    participantId: input.participantId,
    metadata: { reason: input.reason },
  });

  return {
    participantId: input.participantId,
    deletedSessionCount: sessions.length,
  };
}
```

### Retention Worker

```ts
export async function runMediaRetentionJob() {
  const expiredRecordings = await listExpiredRecordings({
    now: new Date().toISOString(),
    limit: 500,
  });

  for (const recording of expiredRecordings) {
    await markRecordingDeleted(recording.id);

    await enqueueStorageDeletion({
      bucket: recording.storage_bucket,
      key: recording.storage_path,
      resourceType: "recording",
      resourceId: recording.id,
    });

    await writeAuditLog({
      workspaceId: recording.workspace_id,
      action: "recording_deleted",
      resourceType: "recording",
      resourceId: recording.id,
      sessionId: recording.session_id,
      metadata: {
        reason: "retention_policy",
        deleteAfterAt: recording.delete_after_at,
      },
    });
  }

  return { processed: expiredRecordings.length };
}
```

## Production Checklist

- Private buckets only.
- Server-generated object keys only.
- Short-lived upload URLs.
- Short-lived read URLs.
- No permanent public URLs.
- No service keys in browser.
- Object metadata stored in Postgres.
- Workspace ownership checked before every signed URL.
- File type, size, duration, and ownership validated before upload URL generation.
- Object existence and size verified after upload.
- Retention worker deletes expired media.
- Participant deletion/anonymization removes or detaches media according to policy.
- Audit logs avoid signed URLs and sensitive identifiers.
